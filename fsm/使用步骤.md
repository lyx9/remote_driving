#### 步骤4：进入演示界面

点击顶部导航栏的 **"Intelligent Dispatch Demo"**。

多次点击 **"Add 10 Vehicles"** 按钮，直到车辆数达到100辆左右。

观察：

- 地图上显示车辆位置（如已配置Amap）

#### 步骤7：测试接管功能

1. 找到一个**红色**（紧急）或**橙色**（高风险）的车辆卡片
2. 点击车辆卡片上的 **"接管车辆"** 按钮
3. 查看弹出的接管确认对话框：
   - AI智能分析结果
   - 风险因素详情
   - 推荐操作措施
   - 操作员匹配信息

4. 勾选确认复选框：
   ```
   ☑ 我已充分理解风险，确认执行远程接管操作
   ```

5. 点击 **"确认接管"** 按钮

#### 步骤8：使用 Remote Assistant

1. 点击任意车辆卡片选中它
2. 观察右侧 **Remote Assistant** 面板：
   - 实时建议每5秒更新
   - 四个优先级级别：
     - 🚨 紧急（红色）
     - ⚠️ 高优先级（橙色）
     - ⚡ 中等（黄色）
     - ℹ️ 提示（蓝色）

3. 尝试快速操作按钮：
   - 点击 **"🚨 紧急指导"**
   - 点击 **"🗺️ 路线优化"**

#### 步骤9：查看数据库记录

1. 按 `F12` 打开浏览器开发者工具
2. 切换到 **Application** 标签页（Chrome）或 **Storage** 标签页（Firefox）
3. 左侧找到 **IndexedDB** → **FSM-Pilot**
4. 查看各个数据表：
   - `vehicles` - 车辆记录
   - `operators` - 操作员记录
   - `takeover_events` - 接管事件
   - `ai_analyses` - AI分析结果

## 🔧 可选配置：API集成

系统支持两个外部API来增强功能，但**完全可选**。

### 豆包 (Doubao) LLM API

**功能**: AI场景分析、驾驶建议

**配置步骤**:
```bash
# 1. 复制环境模板
cp .env.example .env.local

# 2. 编辑 .env.local
VITE_DOUBAO_API_KEY=your_doubao_api_key_here

# 3. 重启服务器
npm run dev
```

**获取API密钥**: https://console.volcengine.com/ark

**未配置时**: 使用本地规则引擎，功能完全正常 ✅

### 高德地图 (Amap) API

**功能**: 实时车辆位置显示

**配置步骤**:
```bash
# 在 .env.local 中添加
VITE_AMAP_API_KEY=your_amap_key_here
VITE_AMAP_JS_CODE=your_amap_js_code_here
```

**获取API密钥**: https://console.amap.com

**未配置时**: 显示配置提示，车辆列表功能正常 ✅

**详细配置说明**: 查看 [docs/API_CONFIGURATION.md](docs/API_CONFIGURATION.md)

## ❓ 常见问题

### Q1: 无法登录，提示 "Invalid username or password"

**A**: 确认使用正确的凭据：
- 用户名: `cityu` (全部小写)
- 密码: `2026` (纯数字)

如果仍然失败：
```bash
# 清除浏览器缓存
1. 按 F12 打开 DevTools
2. Application → Storage → Clear site data
3. 刷新页面 (Ctrl+Shift+R)
4. 重新尝试登录
```

### Q2: 端口 5173 已被占用

**A**:
```bash
# 查找并终止占用端口的进程
lsof -ti:5173 | xargs kill -9

# 或使用其他端口
export DEMO_PORT=5174
npm run dev -- --port 5174
```

### Q3: npm install 失败

**A**:
```bash
# 清除 npm 缓存
npm cache clean --force

# 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### Q4: 演示脚本无法执行

**A**:
```bash
# 确认脚本有执行权限
chmod +x start_demo.sh

# 确认在正确的目录
cd /home/lyx/fsm
./start_demo.sh
```

### Q5: 地图不显示

**A**: 这是正常的！
- Amap API 是可选配置
- 未配置时会显示提示信息
- 其他功能完全正常使用
