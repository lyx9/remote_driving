## 技术实现细节

### 场景参数

**摄像机设置:**
```typescript
camera = new THREE.PerspectiveCamera(
  65,                    // 视角
  aspect,                // 宽高比
  0.1,                   // 近裁剪面
  150                    // 远裁剪面
)
camera.position.set(0, 8, 12)   // 俯视位置
camera.lookAt(0, 0, -5)         // 看向前方
```

**动画速度:**
- 网格移动：0.25 单位/帧
- 障碍物移动：0.25 单位/帧
- 主车摆动：sin(t * 1.2) * 2.5
- 主车转向：sin(t * 1.2) * 0.3 弧度
- 时间系数：t = Date.now() * 0.0008

### 避障逻辑

**核心算法:**
```typescript
for (let i = 0; i < 150; i++) {
  const z = -i * 0.4              // 路径点Z坐标
  const progress = i / 150         // 进度(0-1)

  // 基础S曲线路径
  let x = Math.sin(progress * Math.PI * 3 + t) * 2.5

  // 遍历所有障碍物
  obstacles.forEach(obstacle => {
    const obstacleZ = obstacle.position.z
    const distance = Math.abs(z - obstacleZ)

    // 如果接近障碍物 (< 3m)
    if (distance < 3) {
      // 根据障碍物位置决定避让方向
      const avoidDirection = obstacle.position.x > 0 ? -1 : 1

      // 避让偏移量（距离越近偏移越大）
      const offset = 1.5 * (1 - distance / 3)
      x += avoidDirection * offset
    }
  })

  // 设置路径点坐标
  positions[i * 3] = x       // X轴
  positions[i * 3 + 1] = 0.2 // Y轴(高度)
  positions[i * 3 + 2] = z   // Z轴(深度)
}
```

### 障碍物循环

**位置重置:**
```typescript
obstacles.forEach((obstacle, index) => {
  // 向摄像机移动
  obstacle.position.z += 0.25

  // 穿过摄像机后重置到远处
  if (obstacle.position.z > 5) {
    obstacle.position.z = -40 - (index * 8)
  }

  // 持续旋转
  obstacle.rotation.y += 0.01
})
```
