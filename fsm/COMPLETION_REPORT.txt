📋 系统功能模块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🎮 远程控制 (Remote Control)
   地址: http://localhost:3000/remote-control
   功能: 多路视频墙、LiDAR 3D、车辆遥测、AI 建议

2. 🚗 智能调度 (Intelligent Dispatch)
   地址: http://localhost:3000/intelligent-dispatch-demo
   功能: 车辆队列、风险评分、安全员分配、地图显示

3. 📊 数据库可视化 (Database Visualization)
   地址: http://localhost:3000/database-visualization
   功能: 车辆记录、接管事件、AI 分析、3D 重建

4. 🎬 RosBag 回放 (RosBag Replay)
   地址: http://localhost:3000/rosbag-replay-pro
   状态: ✅ 已发现 10 个 ROS2 bag 文件
   功能: 选择和回放、多相机显示、点云可视化

🎯 演示流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 启动系统
   ./start_all.sh start

2. 等待服务启动（约 10-30 秒）

3. 查看演示指南（可选）
   ./start_all.sh demo

4. 按顺序访问各功能模块：
   → 远程控制（展示核心功能）
   → 智能调度（展示车队管理）
   → 数据库（展示数据分析和 3D 重建）
   → RosBag 回放（展示历史数据回放）

5. 演示完成后停止
   ./start_all.sh stop
