#### 核心功能演示

**A. AI实时驾驶建议** ⭐
- 位置: 顶部横幅
- 功能: 根据车速和AI置信度实时生成建议
- 状态指示:
  - 🟢 正常 (车速适中，AI置信度>85%)
  - ⚠️ 警告 (车速过高或AI置信度低)
  - ℹ️ 信息 (系统初始化或等待数据)

**示例建议:**
```
车速 0-30 km/h:  "功能正常，车速适中，保持安全驾驶"
车速 31-50 km/h: "功能正常，请安全符合限速驾驶" ⭐
车速 >50 km/h:   "功能正常，当前车速较高，请注意安全驾驶"
AI置信度<70%:    "AI置信度较低，建议降低车速或切换手动模式"
```

### 3. AI调度系统演示

#### 调度算法

**A. 加权优先级 (Weighted Priority)** ⭐ 默认
```typescript
优先级计算:
  基础分数: 60-85
  紧急加成: emergency_level >= 3 → +10
  延迟惩罚: latency_ms > 100 → -5
  电量惩罚: battery < 30% → -10
```

**B. 紧急优先 (Emergency First)**
```typescript
排序规则:
  1. emergency_level (降序)
  2. priority_score (降序)
  3. latency_ms (升序)
```

**C. 延迟优化 (Latency Based)**
```typescript
排序规则:
  1. latency_ms (升序)
  2. network_quality (excellent > good > fair > poor)
  3. priority_score (降序)
```
