🚀 快速开始（只需 2 步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 启动系统：
   cd /home/lyx/fsm
   ./start_all.sh start

2. 查看演示指南：
   ./start_all.sh demo

就这么简单！系统会自动启动所有服务。

📋 包含的功能模块
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 远程控制 (Remote Control)
   - 多路视频墙
   - LiDAR 3D 可视化
   - 车辆遥测数据
   - AI 驾驶建议
   地址: http://localhost:3000/remote-control

✅ 智能调度 (Intelligent Dispatch)
   - 车辆队列管理
   - 风险评分系统
   - 安全员分配
   - 地图显示
   地址: http://localhost:3000/intelligent-dispatch-demo

✅ 数据库可视化 (Database Visualization)
   - 车辆记录
   - 接管事件
   - AI 分析
   - 3D 场景重建
   地址: http://localhost:3000/database-visualization

✅ RosBag 回放 (RosBag Replay)
   - 选择和加载 bag 文件
   - 多相机同步回放
   - 点云数据可视化
   - 播放控制
   地址: http://localhost:3000/rosbag-replay-pro
   状态: 已发现 10 个 ROS2 bag 文件 (~18 GB)

🎯 演示流程建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 启动系统
   ./start_all.sh start

2. 等待所有服务启动完成（约 30 秒）

3. 按顺序访问各功能模块：
   → 远程控制（展示核心功能）
   → 智能调度（展示车队管理）
   → 数据库（展示数据分析）
   → RosBag 回放（展示历史数据回放）

4. 演示完成后停止
   ./start_all.sh stop
