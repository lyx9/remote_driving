# FSM-Pilot V2.0 - 数据库可视化快速使用指南

## 🚀 一键启动

```bash
./demo_database.sh
```

就这么简单！脚本会自动完成所有设置。

---

## 📋 演示步骤

### 1. 登录系统
- 用户名: **cityu**
- 密码: **2026**

### 2. 进入数据库页面
- 点击顶部导航: **🗄️ Database**

### 3. 生成模拟数据
- 点击按钮: **生成模拟数据**
- 系统创建: 10车辆 + 5接管 + 3AI分析 + 3操作员

### 4. 浏览数据
切换标签页查看不同数据：
- **🚗 车辆记录** - 车辆状态和位置
- **🎮 接管事件** - 接管历史记录
- **🤖 AI分析** - AI场景分析
- **👥 操作员** - 操作员信息

### 5. 导出数据
- 点击: **📤 导出数据**
- 自动下载 JSON 文件

### 6. 导入数据
- 点击: **📥 导入数据**
- 选择 JSON 文件
- 点击: **确认导入**

---

## 💡 关键功能

| 功能 | 说明 |
|------|------|
| 🔄 刷新数据 | 重新加载所有数据 |
| 📥 导入数据 | 从 JSON 文件导入 |
| 📤 导出数据 | 导出为 JSON 文件 |
| 🗑️ 清空数据 | 删除所有记录 |
| 🎲 生成数据 | 创建模拟测试数据 |

## 🔍 查看数据细节

### 浏览器 DevTools

1. 按 **F12** 打开开发者工具
2. 切换到 **Application** 标签
3. 左侧 → **IndexedDB** → **FSM_Pilot_DB**
4. 点击任意表查看原始数据

---

## ⚠️ 注意事项

1. **数据存储**: 所有数据保存在浏览器本地
2. **清空数据**: 删除操作不可恢复，请先导出备份
3. **浏览器兼容**: 支持 Chrome、Firefox、Edge、Safari 最新版
4. **端口**: 默认使用 3000 端口
