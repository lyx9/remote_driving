## 🎮 演示步骤

### 1. 启动系统
```bash
# Terminal 1: 后端
cd server && npm run dev

# Terminal 2: 前端
npm run dev
```

### 2. 访问应用
打开浏览器: http://localhost:3000

### 3. 测试遥控功能
1. 选择车辆 FSM-01
2. 查看右侧 "REMOTE CONTROL" 面板
3. 按下键盘 W 键 (油门)
4. 观察:
   - ✅ 油门进度条上升
   - ✅ 速度显示增加
   - ✅ 控制状态变为 ACTIVE
5. 按下 A 键 (左转)
6. 观察:
   - ✅ 转向指示器向左移动
   - ✅ 转向角度显示负值
7. 切换档位 (按 D 键)
8. 观察:
   - ✅ 档位按钮高亮
   - ✅ 系统日志记录

### 4. 测试 RosBag 功能
1. 点击右上角 "RosBag Replay"
2. 点击左上角蓝色 "📁 Open Bag" 按钮
3. 选择 .db3 文件
4. 观察:
   - ✅ 加载进度条
   - ✅ 点云显示
   - ✅ GPS 轨迹显示
5. 点击播放按钮
6. 观察:
   - ✅ 时间轴前进
   - ✅ 点云更新
   - ✅ 车辆标记移动
