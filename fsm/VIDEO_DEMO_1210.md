#### 5.4 流式架构演示

**[画面：架构图]**

```
┌──────────────┐         WebSocket          ┌──────────────┐
│              │ ◄─────────────────────────► │              │
│   浏览器     │   消息流式传输 (逐条)        │  Node.js     │
│   客户端     │                             │  服务器      │
│              │ ◄─────────────────────────► │              │
└──────────────┘                             └──────────────┘
                                                     │
                                                     │ SQLite3
                                                     │ 查询
                                                     ▼
                                             ┌──────────────┐
                                             │  RosBag.db3  │
                                             │   (3.7 GB)   │
                                             └──────────────┘
```

**传统方法 vs 流式方法：**

| 特性 | 传统方法 | 流式方法 |
|------|---------|---------|
| 内存使用 | 需要加载整个文件 | 仅加载当前消息 |
| 启动时间 | 慢（需要解析全部） | 快（即时开始） |
| 文件大小限制 | ~2GB (浏览器限制) | >15GB ✓ |
| 网络效率 | 低（传输全部数据） | 高（按需传输） |
| 播放控制 | 有限 | 完全控制 |

#### 8.1 RosBag流式服务器

```javascript
// Node.js后端使用SQLite3
class RosBagManager {
  async streamMessages(topicNames, startTime, endTime, callback) {
    // 流式传输消息，不加载整个文件
    this.db.each(query, params, (err, row) => {
      callback(row); // 逐条发送消息
    });
  }
}
```

**优势：**
- ✅ 支持>15GB文件
- ✅ 低内存占用
- ✅ 快速查找和播放
- ✅ 实时过滤

### 为什么选择FSM-Pilot V2.0？

1. **安全第一** - 多层安全检查和紧急停止
2. **低延迟** - 针对实时控制优化（<100ms）
3. **可扩展** - 云原生架构支持多车辆
4. **高效** - 处理大数据文件无内存问题
5. **现代** - 使用最新Web技术构建
6. **本地化** - 高德地图集成，适合中国市场

### 技术创新

1. **RosBag流式传输** - 处理大文件的新方法
2. **WebRTC集成** - 低延迟视频流
3. **高德地图集成** - 中国地图的一流支持
4. **主题系统** - 一致的橘红色科技美学
5. **数据库管理** - 全面的数据处理

## 📊 系统要求

### 最低要求
- **CPU:** 4核心, 2.5 GHz
- **内存:** 8 GB
- **GPU:** 集成显卡
- **网络:** 10 Mbps
- **操作系统:** Ubuntu 20.04+, Windows 10+, macOS 11+

### 推荐要求
- **CPU:** 8核心, 3.5 GHz
- **内存:** 16 GB
- **GPU:** 独立显卡，4GB显存
- **网络:** 100 Mbps
- **操作系统:** Ubuntu 22.04 LTS
